## ✨ 소개

`index.html` **한 개 파일**만으로 동작하는 SQLD 시험 대비 노트입니다.
별도 서버·빌드·설치 없이 브라우저에서 바로 열 수 있고, 폰트(Pretendard)까지 파일에 내장되어 **오프라인에서도 레이아웃이 깨지지 않습니다.**

애플 스타일의 깔끔한 디자인과 좌측 목차 내비게이션(LNB), 챕터별 핵심 개념·비유 설명·흐름도, 그리고 **채점 가능한 인터랙티브 퀴즈**로 구성되어 있습니다.

## 🎯 주요 기능

| 기능 | 설명 |
| --- | --- |
| 🗂 **챕터 내비게이션(LNB)** | 좌측 사이드바에서 과목·챕터를 클릭해 바로 이동 |
| ⏳ **D-day 카운터** | 시험일(2026-11-14, KST)까지 남은 일수 자동 표시 |
| 📊 **진행률 바** | 스크롤·학습 진행 상태를 상단에 시각화 |
| 📝 **인터랙티브 퀴즈** | 보기 선택 → 정답 확인·채점 (문제 50여 개 수록) |
| 🧪 **실전 기출 2회분** | 회차별 50문항, 총 100문항 모의 풀이 |
| 💡 **쉬운 설명(ELI5)·흐름도** | 핵심 개념을 비유와 도식으로 정리 |
| 🔌 **의존성 0 / 단일 파일** | 외부 CDN·라이브러리 없이 완결, 폰트 내장 |

## 🚀 사용 방법

### 1) 로컬에서 바로 열기
저장소를 내려받은 뒤 `index.html`을 더블클릭하면 끝입니다.

```bash
git clone https://github.com/<your-id>/<repo-name>.git
cd <repo-name>
# index.html 을 브라우저로 열기
```

### 2) GitHub Pages로 배포하기 (권장)
온라인에서 링크로 공유하고 싶다면 GitHub Pages를 사용하세요.

1. 저장소 루트에 `index.html`을 올립니다.
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Source** 를 `Deploy from a branch` 로 설정합니다.
4. 브랜치 `main` / 폴더 `/ (root)` 선택 후 **Save**.
5. 잠시 뒤 생성되는 주소로 접속합니다.

```
https://<your-id>.github.io/<repo-name>/
```

> 📱 모바일·PC 반응형을 지원하므로 어느 기기에서 열어도 동일하게 학습할 수 있습니다.

## 🛠 기술 구성

- **순수 HTML / CSS / Vanilla JavaScript** (프레임워크 미사용)
- **단일 파일 구조** — 모든 스타일·스크립트·웹폰트가 `index.html` 내부에 포함
- **Pretendard Variable** 폰트 Base64 내장 → 외부 요청 없이 타이포그래피 유지
- 외부 네트워크 의존성 없음 → **오프라인 동작 가능**
