# SQLD 올인원 합격노트

비전공자도 강의 없이 **하루 1시간·3주 루틴**으로 SQLD를 준비할 수 있도록, 전 범위 이론과 실전 CBT 모의고사를 한 파일에 담은 학습용 웹앱입니다. 외부 참고 사이트(SQLD양파)의 화면 흐름을 벤치마킹하되, **콘텐츠는 이 노트 자체 이론·기출로 구성**하고 애플풍 디자인 시스템을 그대로 유지했습니다.

## 구성 (좌측 메뉴 = 패널)

| 패널 | 내용 |
| --- | --- |
| **홈** | 히어로 · 기능 카드 3개 · 학습 현황 대시보드 · 시험 정보 · 학습 순서 |
| **3주 공부계획** | Day 1~21 하루치 분량. 날짜를 누르면 완료 체크 → 홈 진도에 반영 |
| **이론 전범위** | 1과목(데이터 모델링) · 2과목(SQL) 챕터 허브 |
| 2-1 ~ 보충 | 본문 + 그림/표 + 챕터별 확인 퀴즈 (총 6개 이론 챕터) |
| **실전 모의고사 CBT** | OMR 답안지 · 90분 타이머 · 자동 채점 · 합격/과락 판정 |
| 기출 1회·2회 해설 | 보기를 누르면 즉시 채점·해설이 열리는 브라우징 모드 |

## 주요 기능

- **학습 현황 대시보드** — 학습 진도(N/21일), 푼 문항, 정답률, 시험까지 D-day를 자동 집계
- **3주 공부계획 체크** — 각 날짜 클릭으로 완료 토글, 다시 누르면 해제
- **CBT 모의고사**
  - 회차 선택: 기출 1회(14문항) · 2회(18문항) · 전체(32문항, 랜덤)
  - OMR 답안지에서 문항 간 자유 이동, 응답 현황 표시
  - 90분 타이머(5분 이하 경고), 시간 종료 시 자동 제출
  - 채점 기준: **전체 60점 이상 합격**, 단 **1과목·2과목 각각 40% 미만이면 과락**(실제 시험 동일)
  - 제출 후 과목별 정답률·과락 여부, 문항별 오답·해설 제공
- **확인 퀴즈** — 각 이론 챕터 끝 문제, 푼 문항·정답률이 대시보드에 누적

## 기술 메모

- **단일 HTML · 외부 의존성 없음** — 인터넷 연결 없이도 동작(폰트는 파일에 내장)
- **진도 저장** — 학습 진도·퀴즈 통계는 브라우저 `localStorage`에 저장. 파일을 내려받아 열거나 정적 호스팅하면 누적·유지됩니다. (저장 불가 환경에서는 오류 없이 세션 내 임시 저장으로 대체되며, 새로고침 시 초기화)
- **CBT 문항 출처** — 모의고사는 `기출 1·2회` 패널의 문제를 실시간으로 읽어와 구성합니다. 문항을 추가·수정하려면 해당 패널의 `.quiz` 블록만 편집하면 CBT에도 그대로 반영됩니다.
- 사이트의 **AI 무한 퀴즈(실시간 생성)·회원 계정**은 서버가 필요해 단일 HTML로는 동일 구현이 어려워 제외했습니다.

## 사용 / 배포

- **바로 보기** — `index.html`을 브라우저로 열면 끝
- **정적 호스팅** — `index.html`을 GitHub Pages·Netlify·사내 정적 서버 등에 올리면 그대로 서비스 가능 (진도 저장은 방문자 브라우저별로 유지)

## 커스터마이즈

- **시험일 변경** — 하단 `<script>`의 `var EXAM_DATE = new Date(2026, 10, 14);` 수정 (월은 0부터 시작 → `10` = 11월). LNB의 "시험까지" 문구와 D-day가 함께 바뀝니다.
- **문항 추가** — `기출 1회`(`#exam1`) / `2회`(`#exam2`) 패널에 `.quiz` 블록을 추가하면 CBT 세트 수가 자동 증가. 과목 구분은 `1과목`/`2과목` 라벨 `pill`을 기준으로 분류됩니다.
- **챕터 추가** — `.panel` 섹션을 추가하고 LNB에 `data-target`으로 연결하면 메뉴에 노출됩니다.
